# CaseMap AI MVI Skeleton

This is a starter Android skeleton for **CaseMap AI** using:

- Kotlin
- Jetpack Compose
- simple MVI contracts
- manual fake repositories
- Navigation Compose

## Included screens

- Home
- New Matter
- Matter Detail
- Analysis Result

## Notes

This is intentionally a **skeleton**, not a full production project.

Not yet included:
- Room
- DataStore
- Hilt
- Retrofit
- real API integration
- clipboard/export helpers
- PII detector
- tests

## Suggested next steps

1. Replace fake repositories with Room-backed repositories
2. Add Hilt for dependency injection
3. Add DataStore for API key/settings
4. Add real LLM API integration
5. Split analysis result into parsed sections
